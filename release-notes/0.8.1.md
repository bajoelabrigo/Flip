## Flip Studio 0.8.1 — seguridad

Versión de mantenimiento con las correcciones pendientes de la auditoría de seguridad.

### Seguridad
- Las claves de API de ElevenLabs y Fish Audio y el token de acceso para agentes ahora se guardan
  **cifradas** para tu usuario de Windows. Las claves guardadas por la versión anterior se cifran
  solas la primera vez que se usan.
- El servidor local para agentes (MCP) rechaza peticiones malformadas o demasiado grandes, en vez de
  acumular datos sin límite.
- La compilación usa versiones fijas de sus herramientas externas.

### Correcciones
- Varios mensajes todavía decían "Flip" en lugar de "Flip Studio".
